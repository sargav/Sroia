# דף "המדריך לבונה" - כל הקבצים

## מה יש כאן

1. **GuidePage.jsx** - כל דף הנחיתה (הקומפוננטה הראשית `GuidePage`, פלוס כל תת-הקומפוננטות: TopBar, HeroSection, VideoSection, WaveDivider, StraightTalkSection, ProductShowcase, StagesSection, BenefitsSection, AboutSection, CTAFormSection). כולל את כל התמונות מוטמעות בתוך הקובץ (base64) כדי שיהיה קובץ אחד עצמאי.

2. **ThankYouPreview.jsx** - תצוגה מבודדת של דף התודה בלבד (לבדיקה/אישור עיצוב).

3. **ravmesser-integration.js** - קוד לשרת ה-Express שלך, מטפל בהתחברות ל-API של רב מסר והוספת לידים. יש הוראות מפורטות בתוך הקובץ עצמו.

4. **api-config.js** - הגדרת axios ל-React, עם כתובת שרת שמגיעה ממשתנה סביבה (כדי שלא תצטרכי לשנות קוד בין פיתוח לפרודקשן).

5. **.env.development / .env.production** - קבצי הסביבה של React (רק כתובת שרת, לא סודות - מותר להעלות ל-git).

6. **gitignore-template.txt** - תבנית ל-.gitignore, אם עוד אין לך כזה בפרויקט (שני שם ל-`.gitignore` בלי הסיומת txt).

## מה עוד צריך לעשות (לא כלול כאן)

- **קובץ `.env` של השרת** (עם Client Secret, User Token של רב מסר) - את יוצרת אותו בעצמך ישירות על השרת, לא מעלים אותו לשום מקום.
- **ה-endpoint המדויק** להוספת ליד ברב מסר (יש הערה על זה בתוך `ravmesser-integration.js`) - צריך לבדוק בתיעוד ה-API המלא שלהם.
- **פיצול הקובץ הגדול** ל-React לקומפוננטות נפרדות (קבצים נפרדים לכל אחת) - כרגע הכל בקובץ אחד לנוחות התצוגה; אם תרצי לפצל, תגידי לי.
- **החלפת התמונות מ-base64 לקבצים אמיתיים** - כרגע כל התמונות מוטמעות כטקסט בתוך הקוד (base64) כדי שהתצוגה המקדימה תעבוד בלי צורך בהעלאת קבצים. לפני שמעלים לאתר האמיתי, כדאי להוציא אותן לקבצי תמונה נפרדים (JPG/PNG) בתיקיית assets, כדי שהעמוד ייטען מהר יותר.
